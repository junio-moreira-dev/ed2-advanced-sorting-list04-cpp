## 📝 Exercises

| # | File | Problem | Technique | Complexity |
|---|---|---|---|---|

## ⚠️ Read the Problem Statement Carefully

- **Exercise 1:** an inversion is a pair `i < j` with `A[i] > A[j]`. Count it in the merge step, when an element of the right half goes before the elements still waiting in the left half. The total can reach N × (N − 1) / 2, which does **not** fit in 32 bits for N = 10⁵ (use `long long`).
- **Exercise 2:** the Merge Sort must be **stable** (on a tie, the element of the left half goes first). The Quick Sort uses a classic partition (Lomuto or Hoare), sorting by length in **descending** order. The statement also asks for the theoretical analysis of why the Quick Sort loses stability.
- **Exercise 3:** use **Lomuto** (last element as pivot) and count only **effective swaps** (`i != j`). Print exactly three lines: the K-th largest, the final vector and the swap count.
- **Exercise 4:** use the **Hoare** partition (two pointers converging) to separate even and odd numbers. Evens come first in **ascending** order, odds after them in **descending** order.

## ⚠️ Leia o Enunciado com Atenção

- **Exercício 1:** uma inversão é um par `i < j` com `A[i] > A[j]`. Conte na etapa de intercalação, quando um elemento da metade direita sai antes dos elementos que ainda esperam na metade esquerda. O total pode chegar a N × (N − 1) / 2, que **não** cabe em 32 bits para N = 10⁵ (use `long long`).
- **Exercício 2:** o Merge Sort deve ser **estável** (em caso de empate, o elemento da metade esquerda sai primeiro). O Quick Sort usa um particionamento clássico (Lomuto ou Hoare), ordenando por tamanho em ordem **decrescente**. O enunciado também pede a análise teórica de por que o Quick Sort perde a estabilidade.
- **Exercício 3:** use **Lomuto** (último elemento como pivô) e conte apenas as **trocas efetivas** (`i != j`). Imprima exatamente três linhas: o K-ésimo maior, o vetor final e o número de trocas.
- **Exercício 4:** use o particionamento de **Hoare** (dois ponteiros convergentes) para separar pares e ímpares. Os pares vêm primeiro em ordem **crescente**, e os ímpares depois, em ordem **decrescente**.
